# RMedia

Сборка RMediaHub на основе Lampa (https://github.com/yumata/lampa-source).
Lampa распространяется по лицензии GNU GPL v2 (файл LICENSE) — её нельзя удалять.

Что изменено:
- название и описание в index.html
- логотип: img/logo-icon.svg и img/logo.svg
- встроенные плагины: plugins/modification.js
- app.min.js: отключена встроенная загрузка плагина Shots (cub.best/plugin/shots).
  При обновлении Лампы с GitHub автора это правку нужно повторить.
